## Reviewed execution plan (self-review before harness implementation)

Create an original coherent 24-document public Cedarvale domain under fixtures/evaluation/anima_multiturn, with stable document IDs and source-level gold queries fixed before retrieval. Do not invent new personas. Use existing village profiles Elin/Mira/Daren and preserve their authored role/style/relationship data. Create six connected four-turn scenarios: ingredients, navigation, quest sequence, factions/history, unknown knowledge and a second-persona replay of the ingredient questions.

The current dialogue boundary accepts one file. Build a deterministic reference anthology from exactly the same 24 documents for dialogue, without per-question source selection or injected answers. Index it separately with the existing parser/chunker/encoder. Report physical file and chunk counts separately from the 24 source-document retrieval benchmark; never combine metrics across the two layouts. Keep secrets out of public reference material; explicitly state unknown facts. Evidence retains anthology file/revision/chunk IDs and embedded original section IDs. Do not claim native document metadata propagation where only section text exists.

Use a thin research harness around unchanged PreviewRunner + LocalRetriever + SocialStore. Acknowledgement is an explicit console-display simulation after an accepted generated response, not a native receipt. Preserve scenario IDs, sequential player inputs, acknowledged full prior replies, complete prompts, retrieved passages, packed IDs, raw provider replies, timings, route/failure status and model identity. Separate chats and providers by isolated DB keys. Stop a conversation on failed generation; never fabricate downstream context.

Calls are explicitly authorized by the attached user task: at most 48 real requests, 400 output tokens/request, sequential, <=30 s transport/60 s turn and spaced >=3 s, stop on auth/quota failure. Use only the existing configured provider; inspect additional profile credential availability without printing values. Do not silently substitute credentials/models. No background core/server changes. Index/state under ignored output/anima_multiturn, public records under research/ieee_paper/experiments. Unit-test harness history acknowledgement, failed-turn exclusion, session isolation, request cap/fatal stopping and rank denominators. Run focused and full offline pytest; no mocks are scientific results.

Evaluation: do not score keywords as semantic success. Publish full traces and a five-axis rubric (retrieval relevance, factual support, direct answer, follow-up coherence, persona). Prepare blank independent rating sheets. If independent human raters are absent, report an explicitly disclosed assistant semantic audit with per-turn claim/support/referent notes, not human judgment or validated accuracy. Include failures. New rank metrics must come from predeclared sources; old 12-document results remain historical supplementary evidence only.

Screenshots: both Computer Use runtimes currently fail to initialize with the Windows sandbox setup error. Inspect available original captures and native receipts. Use a genuine image only if actually obtained; mark the visual-evidence acceptance gate unresolved if capture remains unavailable. Do not interfere with the teammate's system fixes or fake a gameplay frame.

Verdict: conditional go for isolated experiments and report revision. Source-level vs anthology authorization, acknowledgement provenance, short guard limits, untrusted history, corpus/retrieval layout and non-independent semantic evaluation are explicit confounds. No additional runtime infrastructure is justified.
