# I17 independent Skyrim connection layer

Scope: an independently authored SKSE plugin and localhost bridge, using Mantella only as a transport/playback reference. No Mantella edits, image description, new LLM/STT/TTS model, quest mutation or pipeline redesign.

Acceptance: dialogue start/update/end captures scoped actor and currently offered dialogue data; player-view screenshot is saved with metadata; context-ready and player-input messages reach a configurable pipeline boundary; correlated text/audio responses return through a bounded, cancellable game delivery channel. Missing NPC biography/knowledge is explicitly unknown, supplemented only by configured public profiles. Native build and live Skyrim checks are reported separately from offline Python tests.

Placement: independent protocol, bridge, capture/audio helpers and CLI in `src/npc/adapters/skyrim/`; SKSE C++ source/build recipe in its `native/` subtree; tests in `tests/unit/adapters/` and `tests/integration/`; public settings/profiles under `configs/skyrim/`. Runtime output under ignored `output/skyrim/`. Existing preview pipeline is composed through a small optional binding; external pipeline endpoints remain configurable. Screenshot files deliberately have no VLM consumer.

Approach: menu event + bounded main-thread observation, worker-thread localhost HTTP, no engine object access on network workers. Engine menu topics are observations of currently offered dialogue, not a full quest-condition evaluator. Adapter-local schema retains facts not understood by the current canonical context builder. Bridge stores bounded session/turn state, cancels obsolete output, accepts typed STT text and optional WAV->configured STT HTTP, and stages verified PCM WAV for engine-attached playback. Avoid an ESP/Papyrus compiler requirement by using native engine sound/subtitle APIs; facial movement is best effort and must be declared if implemented.

Plan self-review (not independent): preserve save/load isolation with a new session on load; never equate game relationship rank with trust; never infer NPC knowledge from nearby player-visible content; reject uncorrelated/late output; allow at most one active turn and one delivery; lost delivery polling must not replay audio; screenshot failure does not fail context capture. Bind only to loopback. Do not synthesize or record by default in offline tests. Audio paths must be contained under configured roots; all work, body sizes, retention and HTTP timeouts are bounded.

Tests: actor and profile mapping, dialogue provenance, screenshot success/failure/retention with fake capture, WAV validation/path containment, context callback and player input ordering, duplicate/late response, cancellation/end/session replacement, polling redelivery versus explicit receipt, failed pipeline and stale callback, HTTP route validation, built-in preview smoke with fake provider. Run focused tests then `.venv/Scripts/python.exe -m pytest`; compile native plugin if toolchain can support CommonLib, record blockers honestly. Review actual diff and update connector guide with exact build/setup and endpoint examples.
